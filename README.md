## 📖 درباره‌ی پروژه

**Quiz Pro** یک پلتفرم آزمون آنلاین کامل است که با **جاوااسکریپت خالص** (بدون هیچ فریمورک) ساخته شده. این پروژه برای کسانی طراحی شده که می‌خوان یک اپلیکیشن واقعی و کاربردی با HTML/CSS/JS بسازن و توی پورتفولیوی خودشون داشته باشن.

پروژه شامل **دو نقش** (ادمین و کاربر عادی)، **مدیریت دسته‌بندی سلسله‌مراتبی**، **سیستم دستاورد**، **نمودارهای آماری** و **حالت تاریک** است.

## ✨ ویژگی‌ها

### 🔐 احراز هویت
- ثبت‌نام کاربر جدید با اعتبارسنجی کامل
- ورود با نام کاربری و رمز عبور
- **کپچای Canvas** برای امنیت بیشتر
- نمایش/مخفی کردن رمز عبور
- ذخیره‌ی نشست در `localStorage`

### 👑 پنل ادمین (Role-based Access)
- **دسترسی محدود** — فقط ادمین می‌تواند وارد شود
- **مدیریت سوالات** — افزودن، ویرایش، حذف، جستجو و فیلتر
- **مدیریت دسته‌بندی‌ها** — افزودن/حذف دسته و زیرشاخه به صورت داینامیک
- **خروجی و ورود JSON** — برای پشتیبان‌گیری و بازیابی
- **آمار سراسری سایت** — نمودارها و لیست کاربران
- **مدیریت کاربران** — مشاهده‌ی لیست کاربران با آمار هرکدام

### 🎯 سیستم آزمون
- **۴ دسته‌بندی پیش‌فرض** با قابلیت توسعه:
  - 💻 برنامه‌نویسی (Python, HTML/CSS, JavaScript)
  - 🗄 پایگاه داده SQLite
  - 🖥 ICDL
  - 🎨 Photoshop
- **۲ حالت بازی:** زمان‌دار و تمرینی
- **۳ سطح سختی:** آسان، متوسط، سخت
- **تصادفی‌سازی سوالات و گزینه‌ها**
- **تایمر معکوس** با هشدار بصری

### 🏆 دستاوردها و انگیزش
- **۸ نشان قابل باز کردن** (اولین آزمون، بی‌نقص، استریک ۳ و ۷ روزه و ...)
- **استریک روزانه** — هر روز آزمون بده تا استریکت حفظ بشه
- **کانفتی جشن** برای نمرات بالای ۷۵٪
- **افکت‌های صوتی** با Web Audio API (بدون فایل)

### 📊 آمار و گزارش
- **۳ نمودار Canvas:**
  - روند موفقیت (نمودار خطی)
  - عملکرد هر دسته (نمودار میله‌ای)
  - توزیع سختی (نمودار دایره‌ای)
- **تاریخچه‌ی کامل آزمون‌ها**
- **صفحه‌ی مرور پاسخ‌ها** با فیلتر (درست/غلط/بی‌پاسخ)

### 🎨 طراحی و UX
- **تم بنفش/سفید/مشکی** با متغیرهای CSS
- **حالت تاریک و روشن** با ذخیره‌ی انتخاب کاربر
- **Glassmorphism** و انیمیشن‌های نرم
- **کاملاً ریسپانسیو** برای موبایل و دسکتاپ
- **RTL** با فونت وزیرمتن
- **آیکون‌های Boxicons**

### 🔧 امکانات اضافی
- **اشتراک‌گذاری نتیجه** به صورت تصویر PNG
- **میانبرهای کیبورد** (۱-۴، Enter، Arrow، S، D، Esc)
- **ذخیره‌سازی کامل** در `localStorage`
- **صفحه‌ی راهنما** برای کاربران جدید
